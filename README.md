# Prograci-n-de-dispositivo# TecniCerca

## Ficha de Idea de Producto

### Nombre Tentativo de la App
**TecniCerca**

### Problema que Resuelve
Las personas tienen dificultades para encontrar técnicos confiables cuando necesitan reparar, instalar o dar mantenimiento a equipos e infraestructuras en sus hogares o negocios. Frecuentemente deben depender de recomendaciones informales, lo que consume tiempo y no garantiza la calidad del servicio.

### Usuario Objetivo (Perfil)

#### Clientes
- Personas que necesitan servicios técnicos para el hogar.
- Dueños de pequeños negocios.
- Administradores de propiedades.

#### Técnicos
- Electricistas.
- Plomeros.
- Albañiles.
- Ebanistas.
- Pintores.
- Técnicos de refrigeración.
- Técnicos de informática.

### Jobs To Be Done

1. Encontrar rápidamente un técnico confiable cerca de mi ubicación.
2. Comparar técnicos según calificaciones y opiniones de otros usuarios.
3. Solicitar un servicio de manera rápida y segura desde el celular.

### Propuesta de Valor

**TecniCerca conecta a los usuarios con técnicos confiables cercanos, facilitando la contratación de servicios de manera rápida, segura y eficiente.**

### Tipo de Aplicación

**Negocio / Servicios**

# Backlog Inicial

## Prioridad Alta

### HU-01
**Como** usuario, **quiero** registrarme en la aplicación **para** acceder a los servicios disponibles.

### HU-02
**Como** usuario, **quiero** iniciar sesión **para** gestionar mis solicitudes de servicio.

### HU-03
**Como** usuario, **quiero** buscar técnicos por categoría **para** encontrar el servicio que necesito.

### HU-04
**Como** usuario, **quiero** visualizar técnicos cercanos **para** reducir el tiempo de búsqueda.

### HU-05
**Como** usuario, **quiero** solicitar un servicio **para** contactar rápidamente a un técnico.

### HU-06
**Como** usuario, **quiero** ver las calificaciones y opiniones de otros clientes **para** elegir un técnico confiable.

## Prioridad Media

### HU-07
**Como** técnico, **quiero** crear un perfil profesional **para** promocionar mis servicios.

### HU-08
**Como** técnico, **quiero** recibir notificaciones de nuevas solicitudes **para** responder rápidamente a los clientes.

### HU-09
**Como** usuario, **quiero** dejar comentarios después del servicio **para** ayudar a otros clientes en su elección.

## Prioridad Baja

### HU-10
**Como** usuario, **quiero** guardar técnicos favoritos **para** contactarlos nuevamente en el futuro.

### HU-11
**Como** usuario, **quiero** recibir recomendaciones personalizadas **para** encontrar técnicos adecuados a mis necesidades.

### HU-12
**Como** administrador, **quiero** generar reportes de actividad **para** analizar el uso de la plataforma.

# Prompt Utilizado

```text
Genera una ficha de idea de producto para una aplicación móvil que conecte usuarios con técnicos de servicios del hogar (electricistas, plomeros, albañiles, ebanistas, pintores, técnicos de refrigeración y técnicos de informática). Incluye nombre tentativo, problema que resuelve, usuario objetivo, 2-3 jobs to be done, propuesta de valor en una oración, tipo de aplicación y un backlog inicial con historias de usuario en formato "Como [usuario], quiero [acción] para [beneficio]", clasificadas por prioridad alta, media y baja.
```
